## 新手最容易踩的四个坑

最常见的有四个：把试用环境当正式环境、配置买太小、不算备案时间、只看首购价。

**把试用环境当正式环境。** 西部数码的试用条款写得很直白：试用期72小时，到期自动删除，转正前不要放正式数据。其他平台的免费额度也一样，注意有效期从注册日起算、且只覆盖指定规格，转正前记得把数据迁走。

**配置买太小。** 西部数码在配置选择页直接提醒：单核在很多场景容易vCPU 100%占用影响性能，建议至少双核、内存1G以上。对照主流平台的入门档位，1核0.5G到1核1G只够最轻量的测试，正经挂站从2核1G起步更稳妥。

**不算备案时间。** 大陆地域服务器要绑定域名对外访问，必须先走完ICP备案流程，未备案的域名无法访问。赶上线时间的项目，可以先把业务放在香港或海外节点过渡。

**只看首购价。** 特惠活动通常限定计费周期和适用人群。下单前看清两点：优惠价覆盖多长周期、到期后按什么标准续费。把第一年价格和之后的标准价分开算，才是真实成本。
